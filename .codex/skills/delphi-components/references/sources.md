# Fontes e referências locais

Esta skill foi construída a partir do design system e do dashboard fornecidos pelo usuário, armazenados em `assets/reference/`.

Ao aplicar em um repositório, a fonte de verdade para compatibilidade é o código-fonte/documentação da versão do RAD Studio instalada e os arquivos do próprio projeto. Não presuma que classes auxiliares de StyleHook tenham assinaturas idênticas em todas as versões.
