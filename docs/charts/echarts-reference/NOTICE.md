# Apache ECharts reference

The chart defaults, bar spacing rules, and constrained smooth-line control-point
calculation are based on Apache ECharts 6.1.0. The Pascal implementation is modified
for Skia4Delphi and native Windows text. It is not an Apache product or an endorsed
implementation.
